# UX audit — 22 Oct 2026 (prioritised fixes, no new features)

Decisions taken from this audit (Miguel's brief: «mais friendly use, o mais fácil de perceber, sem invenções»):
- **Language:** the app is English everywhere except `/contabilista/` (Portuguese, for the accountant). Mixed PT/EN on one screen is a P1.
- **Blue means one thing:** one primary (blue) button per screen — the main action. Everything else is `btn-s` (secondary) or a text link. Selected filters are pills (`.pill.active`), never blue buttons.
- **Plain words, no codes:** never show slugs, column names, `source_kind`, `needs_review`, `attributed_location`, «Supabase», file paths or SQL hints to users.
- **Empty states say what to do**, and distinguish «nothing yet» from «nothing matches these filters» (with a Clear filters button).
- **Mobile (390px):** nothing a staff member needs may be hidden; stack instead of hiding.

P1 = confusing or blocks a task · P2 = slows the user · P3 = polish. Paths relative to the repo root; line numbers are from 22 Oct 2026 (grep the quoted strings).
